# RAG Concepts Quiz

An interactive web quiz designed to test and explain core concepts behind **Retrieval Augmented Generation (RAG)** used in modern AI systems.

This project demonstrates a simple AI-themed interface built with **HTML, CSS, and JavaScript** while introducing important ideas used in **LLM-based applications**.

---

# Overview

Retrieval Augmented Generation (RAG) is an architecture commonly used in AI systems where:

1. A **user query** is received  
2. A **retriever** searches relevant information from a **vector database**  
3. Retrieved context is sent to an **LLM**  
4. The **LLM generates the final response**

This quiz visually introduces these concepts through interactive questions.
